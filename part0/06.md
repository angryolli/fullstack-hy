## 0.4: New note diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a new note and clicks Save

    Note right of browser: JavaScript prevents the default form submission and creates a new note object

    Note right of browser: The note is added to the local notes list and the page is redrawn

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    Note right of browser: Request payload: {content: "jauuu", date: "2026-09-08T10:15:58.487Z"}
    activate server
    Note right of server: Server stores the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: The browser stays on the same page - no reload or redirect
```
